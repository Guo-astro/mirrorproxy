# MirrorProxy v1.7.1

MirrorProxy v1.7.1 improves account and administration usability, download-token setup, and Agent installation compatibility.

## Highlights

- Present user and group download grants with identifiable names and clear revoke behavior. Preserve inherited permissions and existing authorization controls.
- Display a newly created download token once, alongside copyable shell-specific setup commands. The CLI prompts on interactive stdin and continues to accept piped tokens.
- Refine account and administration forms, invitation history, mirror health tables, session records and mobile layouts. Add consistent public-page footers and improve text contrast and heading semantics.
- Extend Agent setup compatibility and fix Windows installer behavior.

## Security and compatibility

Existing configuration, routes, database and download authorization remain compatible. The npm audit retains a temporary exception for [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4), affecting the deepmerge build-tool dependency; other advisories still fail the audit. Remove this exception when a compatible upstream fix is available.

Upgrade using the matching release artifact and verify its published checksum before replacing the executable. Preserve the configuration and database. Roll back by restoring the previous executable if necessary.

## Verification

Release validation includes locked Rust checks, frontend build and browser tests, administration smoke tests, and dependency audits. Consult the CI run for the release commit for exact results.
